PNE Battery Analyzer v2.6 — 반응형 UI 개선 소스

변경 범위
- CYC/StepEnd 해석, dQ/dV, Cycle Life, DCR/SOC 계산 로직과 API는 수정하지 않았습니다.
- 화면 구조와 조작 흐름만 개선했습니다.

주요 개선
1. 데이터 입력 흐름 단순화
   - 기본 화면: ZIP 선택 → 결과 폴더 선택 → 분석 시작
   - 상위 폴더 선택, 직접 경로 입력, 채널별 Raw CSV 자동 생성은 "고급 입력 옵션"으로 정리했습니다.

2. 공통 채널 선택 추가
   - 분석 후 상단에 현재 데이터/채널 목록이 표시됩니다.
   - 원하는 채널을 체크한 뒤 "선택을 모든 분석에 적용"을 누르면 Summary, Cycle Life, dQ/dV, DCR의 각 채널 선택에 한 번에 반영됩니다.
   - 탭별 개별 선택 기능은 그대로 유지됩니다.
   - 긴 파일명은 줄이지 않고, 마우스를 올리면 전체 이름을 확인할 수 있습니다.

3. 분석 화면의 정보 구조 개선
   - 상단 탭을 한 줄 작업 네비게이션으로 정리했습니다.
   - 화면 폭이 작으면 탭 바가 가로 스크롤로 바뀝니다.
   - dQ/dV의 보간/SG/피크 파라미터는 "고급 파라미터"에 넣어 기본 화면의 밀도를 낮췄습니다.
   - DCR은 ① Pulse 자동 검출 → ② 검토 및 SOC 보정 → ③ 지정 시점 결과의 세 단계로 구분했습니다.
   - 긴 표는 고정 헤더와 독립 스크롤을 사용합니다.

4. 반응형 레이아웃
   - 넓은 화면에서는 채널 공통 선택과 조작 버튼을 한 행에 배치합니다.
   - 태블릿/작은 창에서는 공통 선택, 컨트롤, 버튼이 세로로 자연스럽게 재배치됩니다.
   - 모바일 폭에서는 입력/분석 컨트롤이 한 줄씩 표시되고, 표는 가로 스크롤로 원본 값을 보존합니다.

검증 결과
- Go 소스에서 HTML을 조합해 필수 ID 존재 여부를 확인했습니다.
- 조합된 전체 JavaScript의 문법 검사를 통과했습니다.
- 이 작업 PC에는 Go 컴파일러가 설치되어 있지 않았습니다. 공식 Go 배포본 다운로드도 네트워크 인증 오류로 실패해, 수정 EXE 빌드는 수행하지 못했습니다.
- 따라서 이 배포본의 EXE(v2.5)는 기존 파일이며, v2.6 UI 변경은 source\full_gui.go 와 source\gui_html.go에만 반영되어 있습니다.

빌드 방법 (Go 설치 PC)
1. source 폴더에서 PowerShell을 엽니다.
2. go test ./... 를 실행합니다.
3. go build -o PNE_Battery_Analyzer_v2.6_UI.exe . 를 실행합니다.
4. 생성한 EXE를 실제 PNE ZIP으로 수동 확인합니다.

주의
- 실제 회사 PNE 데이터 및 Windows GUI 수동 실행 검증은 이 환경에서 수행하지 않았습니다.
- 원본 v2.5 ZIP/EXE는 변경하지 않았습니다.
