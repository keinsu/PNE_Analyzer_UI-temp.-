# Battery Analysis Studio 3.1

PNE 시험 입력과 Qt 분석 작업공간을 통합한 Windows 오프라인 배터리 분석 프로그램입니다. 기존 Go·Qt 프로그램은 변경하지 않고 별도 폴더에서 개발했습니다.

## 실행

기본 배포 ZIP은 **전체 압축 해제**한 뒤 `BatteryAnalysisStudio/BatteryAnalysisStudio.exe`를 실행하세요. 옆의 `_internal` 폴더도 반드시 함께 보관하세요. Python 설치나 인터넷 연결은 필요하지 않습니다.

`BatteryAnalysisStudio_v3_OneFile.exe`는 단일 파일 배포본입니다. EXE 하나만 전달하거나 원하는 위치로 복사해 실행할 수 있습니다. 실행할 때마다 Windows 임시 폴더에 필요한 구성요소를 잠시 풀기 때문에 폴더형보다 첫 실행이 느릴 수 있습니다.

소스에서 실행하는 경우 Windows 64비트 Python 3.13 환경에서:

```powershell
python -m pip install -r requirements.txt
python main.py
```

합성 예제 화면을 열려면 `python main.py --demo`를 사용합니다. 배포 EXE도 `--demo`를 지원합니다. 예제는 SYNTHETIC으로 표시되며 실제 장비 검증 자료가 아닙니다.

## 기본 사용 순서

1. `＋ 데이터`에서 PNE ZIP 또는 Raw CSV를 선택하거나 `폴더`로 시험 폴더를 선택합니다. 파일·폴더를 창에 끌어놓아도 됩니다.
2. 왼쪽 시험/채널 목록에서 표시할 채널을 체크합니다. 목록의 선택 행은 DCR·원본 표의 활성 채널입니다.
3. Summary에서 전체 추이를 확인하고 Cycle Life·Raw·미분·DCR로 이동합니다. 같은 파일을 분석마다 다시 불러오지 않아도 됩니다.
4. 오른쪽 `분석 설정`에서 조건을 지정한 뒤 `현재 조건으로 분석`을 누릅니다. 설정 패널은 상단 버튼으로 접을 수 있습니다.
5. 프로젝트를 저장하면 원본 참조, 선택 채널, 분석 조건, DCR 수동 수정, 축 범위 등을 다음 실행에서 복원할 수 있습니다.

원본 파일은 읽기 전용입니다. 프로젝트는 원본 파일 자체를 복제하지 않으므로 원본을 함께 보관하세요. 원본 경로가 바뀌면 프로젝트 열기 과정에서 다시 연결할 수 있습니다. 원본 내용이 바뀌면 다른 자료로 인식하며 기존 수동 수정의 적용 여부를 확인해야 합니다.

## 시험 목록에서 누적 관리

1. 상단 **시험 목록 → 새 시험**에서 이름을 정합니다.
2. 시험에서 **＋ 데이터**를 눌러 **수명시험(CYC)** 또는 **RPT**를 선택합니다. 수명시험은 원본 채널마다 기존 셀 또는 새 셀을 지정하고, 새 구간의 누적 시작 Cycle을 입력합니다.
3. 진행 중인 파일은 **시험 구간 · 이력 → 최신 파일로 갱신**에서 같은 구간으로 반영합니다. 동일한 스냅샷과 이전 스냅샷은 기존 값을 유지합니다. 변경된 이전 Cycle은 적용 전 확인할 수 있습니다.
4. 시험 목록에서 다시 열면 Summary와 저장한 분석 설정이 복원됩니다. RPT는 파일 목록에만 등록합니다.

시험 데이터는 Windows 사용자별 로컬 폴더 `%LOCALAPPDATA%\BatteryAnalysisStudio\Studies`에 저장됩니다. 수명시험은 집계표와 디코딩한 측정 데이터를 보존합니다. 구간 제외와 직전 상태 복원은 시험 기록만 바꾸며, 디스크의 측정 데이터는 유지합니다. EXE만 다른 컴퓨터에 복사하면 시험 기록은 따라가지 않습니다. 백업은 해당 시험 폴더 전체를 대상으로 하세요.

## 입력과 매핑

- PNE ZIP, 시험 폴더, 개별 채널 폴더, CYC 파일, Raw CSV/TSV를 지원합니다.
- ZIP 최상위에 시험 폴더가 더 있어도 하위 채널을 탐색합니다.
- ZIP·폴더의 PNE 채널은 같은 폴더에서 정상적으로 연결되는 `CYC + StepEnd.csv` 쌍만 등록합니다. 연결되지 않은 CYC와 PNE 폴더 안의 보조·이전 출력 CSV는 빈 중복 채널로 만들지 않고 가져오기 안내에 기록합니다.
- 한 채널 폴더에 정상 파일 쌍이 여러 개 있으면 자동 병합하지 않고 CYC 파일명을 덧붙여 서로 구분합니다.
- 일반 CSV는 컬럼을 자동 인식합니다. 자동 인식이 맞지 않으면 `파일 → CSV 컬럼·단위 지정하여 열기`를 사용합니다.
- 수동 입력에서 헤더 행·구분자·Cycle·전압·전류·시간·Step·용량·온도·에너지 컬럼과 단위를 지정할 수 있습니다.
- 여러 파일은 기본적으로 독립 채널/셀입니다. 같은 셀의 연속 기록에만 `같은 셀의 분할시험 연결`을 사용하고 Cycle Offset을 명시적으로 입력하세요. 같은 Cycle 일부가 겹치는 파일은 임의로 합치지 않습니다.
- 실제 Cycle 0을 보존합니다. 미매칭 등 Cycle을 알 수 없는 원본 행은 내부적으로 −1로 구분합니다. 반복 Cycle은 원본 번호를 별도 보존하면서 내부 식별 번호로 구분합니다.

## 분석 화면

### Summary / Cycle Life / Channel Compare

용량·용량 유지율·에너지·에너지 유지율·CE/EE·온도·CC/CV·시작 저항을 선택할 수 있습니다. Summary는 기본적으로 Cycle 2부터 표시합니다. 기준 Cycle을 비우면 Cycle 2부터 첫 유효 방전 Cycle을 사용합니다. 번호를 직접 입력하면 해당 채널에 그 번호의 유효 방전용량이 있어야 합니다. 표시 시작 Cycle과 유지율 기준 Cycle은 각각 변경할 수 있습니다.

상단 카드는 현재 활성 채널의 마지막 분석 Cycle 값입니다. DCR·RPT 등 서로 다른 시험 구간이 같은 입력 안에 있으면 Cycle 번호와 실제 Step을 확인하여 해석하세요. 자동 이상 셀 판정 기능은 제공하지 않습니다.

기본 집계는 물리 Step별 대표값입니다. 단일 충전·방전 Step에서는 기존 Qt 계산과 동등성을 검증했습니다. 다단 시험의 합계가 필요한 경우 집계 방식을 명시적으로 바꾸세요. 자세한 수식은 `docs/calculation_rules.md`를 참조하세요.

### Raw Curve

Cycle은 `1,5,10-50:5` 형식으로 입력합니다. X/Y축·방향·StepNo를 선택할 수 있습니다. 물리적으로 다른 Step은 별도 곡선으로 표시합니다.

`상세 데이터 보기`를 누르면 표시 곡선 목록과 Step 매칭표, 원본 데이터 탭이 열립니다. 원본 데이터는 10,000행씩 표시하며 초기화·미매칭 행도 확인할 수 있습니다. 상세 표 CSV 내보내기는 현재 표시한 표를 저장합니다. 전체 행을 저장하려면 Export에서 활성 채널 Raw CSV를 선택하세요.

### dQ/dV · dV/dQ

충전·방전·양방향, Cycle 목록, StepNo, 보간점, SG 스무딩, 윈도, 다항식 차수, 피크 돌출도를 조절합니다. 기본값은 500점, 스무딩 켬, 자동 윈도(500점에서 21), 3차, 피크 돌출도 5%입니다.

각 Cycle·방향에서 선택한 물리 Step을 분석합니다. Step을 비우면 가장 많은 유효 점을 가진 연속 구간을 고르며 선택 Step을 곡선 이름에 표시합니다. V–Q, dQ/dV, dV/dQ, 피크 표, 피크 추이를 제공합니다. 최소 피크 간격과 피크 추적 허용 이동폭을 mV 단위로 조절할 수 있습니다. 추적 허용폭 기본값은 50mV이며 피크의 물리적 동일성은 검토해야 합니다.

조건을 바꿨다면 재분석하세요. 이전 조건으로 계산한 그래프의 저장 버튼은 비활성화됩니다.

### DCR / SOC

현재 활성 채널을 사용합니다. `탐지 → Pulse/SOC 검토 → 분석 결과` 순서로 진행합니다. Pulse 포함/제외, SOC 블록 번호·SOC%, Setting StepNo, 최대 Pulse 시간, Return 용량 검토 기준, 측정 시각을 조절합니다.

- 용량 균형은 블록/Return 검토에 사용하며 절대 SOC%를 자동으로 확정하지 않습니다.
- SOC가 없으면 블록 또는 기준전압 표시를 사용합니다. SOC%와 전압을 한 축에 혼합하지 않습니다.
- 반복 측정은 개별 유지합니다. Return 불균형만으로 Pulse를 자동 삭제하지 않습니다.
- 검토 행을 선택하면 Raw 전압·전류와 V0/측정 시각을 확인할 수 있습니다.
- V0 출처·실제 휴지 전류·시간별 적용 전류·계산 불가 사유를 결과에 보존합니다.
- 측정 범위를 벗어나는 시각은 외삽하지 않습니다. 큰 기록 공백을 넘는 보간도 제한합니다.
- 수동 수정은 실행 취소·초기화·프로젝트 저장/복원이 가능합니다.

## 공통 그래프 조작

- `영역 확대`와 `그래프 이동` 버튼으로 마우스 모드를 전환합니다.
- X/Y 최소·최대 값을 입력하거나 `전체 보기`, `이전 범위`를 사용합니다.
- 그래프 옆 곡선 목록에서 체크를 해제하면 숨기고, 행을 선택하면 해당 곡선을 강조합니다.
- Hover는 선택 곡선을 우선하고 실제 원본 배열에서 좌표를 찾습니다. Raw의 실측점과 미분의 계산점을 구분합니다.
- Raw와 미분 그래프는 같은 Cycle 번호에 같은 색을 사용합니다. 범례에서 Cycle 번호를 검색하거나, 클릭해 강조하거나, 체크를 해제해 숨길 수 있습니다. 필요하면 분석 설정에서 채널 기준 색상으로 바꿀 수 있습니다.
- 곡선은 어두운 배경용 고대비 색상을 사용하며 기본 선 굵기는 1.8px입니다. 방전 곡선은 색상과 함께 점선으로 구분합니다.
- 하단 표는 선택 후 Ctrl+C로 Excel에 붙여넣을 수 있습니다. 열 제목을 눌러 정렬합니다.
- 그래프 PNG와 표시 중인 곡선 CSV를 각 그래프에서 저장합니다.
- Windows의 Origin과 데스크톱 PowerPoint가 있는 PC에서, 붙여넣을 PPT를 열고 편집 화면에서 슬라이드를 선택하세요. Raw Curve, dQ/dV, V–Q, dV/dQ에서 **PPT에 그래프 붙여넣기**를 누르면 범례에서 체크한 Cycle이 편집 가능한 Origin 그래프로 삽입됩니다. 여러 셀이 표시 중이면 한 셀을 선택합니다. PPT는 PowerPoint에서 저장하세요.

## 저장

- `Ctrl+S`: 프로젝트 (`.basproj`) 저장
- `Ctrl+Shift+O`: 프로젝트 열기
- `Ctrl+E`: 선택 채널 분석 Excel 저장
- Export: 현재 분석 표 CSV, 활성 채널 전체 Raw CSV, 프로젝트 및 프리셋
- 분석 프리셋은 다른 시험에 적용할 계산·표시 조건이며, 특정 채널의 수동 SOC/Pulse 수정은 프로젝트에 저장합니다.

Raw CSV는 요청한 경우에만 생성합니다. 기본 저장 위치는 사용 가능한 경우 `D:\Downloads`, 없으면 Windows 다운로드 폴더 등 쓰기 가능한 위치입니다. Excel에는 원본 참조·계산 설정·Step 상태도 기록합니다. 대량 Cycle/Step 표는 시트를 분할합니다.

## 검증과 한계

`validation/`의 JSON·로그와 `docs/validation_report.md`, `docs/decoder_validation.md`를 확인하세요.

- 합성 PNE 바이너리·CP949 CSV·매칭·수식·화면 흐름·취소·설정 복원을 자동 테스트합니다.
- 단일 Step의 기존 Qt 요약·기본 미분 계산과의 수치 동등성을 검사합니다.
- EXE 검증은 생성된 Windows 실행파일 자체로 창 구성·입력·계산·프로젝트 저장/읽기를 실행합니다.
- **실제 장비 PNE 데이터와 별도 회사 PC에서의 검증은 아직 수행하지 않았습니다.** 합성 자료 통과를 실제 장비 정확성 검증으로 간주하지 않습니다.
- 72B 헤더·176B 레코드와 날짜/장비 저항 필드는 제조사 공식 규격이 아닌 역분석 프로필입니다. 지원하지 않는 구조는 임의 해독하지 않습니다.
- 가져올 때 채널 단위로 원본을 해석해 Windows 로컬 임시 저장소에 정확한 데이터와 Cycle 검색 정보를 저장합니다. Raw와 미분은 선택한 Cycle·열만 읽습니다. 디스크 쓰기가 제한된 환경에서는 메모리 방식으로 가져올 수 있습니다.
- 긴 Raw 곡선은 시작·끝과 구간별 극값을 보존하는 미리보기를 사용합니다. 일반적인 Step 시간–전압과 전압–용량 미리보기는 가져올 때 저장합니다. 단조 X축에서 확대하면 화면 범위에 맞게 해상도가 올라갑니다. 계산·실측값 조회·CSV는 전체 측정값을 사용합니다.
- 처음 Summary 분석에서 대표값과 Step 합계 집계를 함께 준비해 로컬에 저장합니다. 기준 Cycle을 바꿀 때는 저장된 집계표에서 유지율만 구합니다. 분석에 포함된 검토 구간이 바뀌면 처음 한 번 별도로 집계합니다.
- 단일 EXE는 실행 시 임시 폴더를 사용합니다. 보안 제품의 검사 정책이나 임시 폴더 사용이 엄격한 회사 PC에서는 폴더형 배포본이 더 안정적일 수 있습니다.

## 재빌드 및 테스트

```powershell
python -m unittest discover -s tests -v
python main.py --smoke-test validation/source_smoke.json
python -m PyInstaller --noconfirm BatteryAnalysisStudio.spec
python tests/verify_frozen.py
python -m PyInstaller --noconfirm --clean --distpath dist_onefile --workpath build_onefile BatteryAnalysisStudio_OneFile.spec
python tests/verify_frozen.py --exe dist_onefile/BatteryAnalysisStudio_v3_OneFile.exe --result validation/onefile_frozen_smoke.json
```

`build_exe.bat`는 테스트·빌드·EXE 검증을 순서대로 실행합니다. 기존 Qt DLL 충돌 사례를 반영해 무관한 Poppler ICU DLL은 포함하지 않습니다. 라이브러리 버전을 변경하면 EXE 자체를 다시 검증해야 합니다.
