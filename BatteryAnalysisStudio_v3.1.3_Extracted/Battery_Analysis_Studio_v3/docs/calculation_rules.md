# v3.0 계산 기준과 회귀 검증 범위

## 공통

- 계산용 단위: V, mA, mAh, mWh, s, °C. 표시용 단위 변환은 원본 데이터와 구분한다.
- 기본 정량분석에는 `MATCHED`와 일반 CSV의 `CSV` 상태만 포함한다. `REVIEW`는 사용자가 포함을 선택할 때만 사용하고 `INITIAL`·`UNMATCHED`는 포함하지 않는다.
- 원본 채널 DataFrame은 변경하지 않는다. 축 범위, 강조, 숨김, 표 복사 때문에 계산용 데이터가 바뀌지 않는다.
- 사용자가 요청한 기준 Cycle이 없거나 유효한 양의 방전용량을 갖지 않으면 오류를 반환한다. 임의로 다른 Cycle을 대신 사용하지 않는다.
- 계산 실패는 요약표 `AnalysisError` 또는 곡선의 `error`로 보존한다. 표에 빈 값으로 남겼다는 이유로 성공으로 처리하지 않는다.

## Cycle Life

- 기본 집계는 각 Cycle의 방향별 최대 용량 물리 Step을 사용한다. 단일 충전·방전 Step 시험에서는 보존한 Qt 엔진의 결과와 일치한다.
- 여러 Step을 한 방향으로 섞으면 CC/CV 시간과 미분 범위가 모호해지므로 대표 Step을 선택하며, 선택 Step과 Step 개수를 표에 남긴다.
- 선택적인 `step_sum` 집계는 물리 Step마다 마지막 값과 첫 값의 차이 절댓값을 더한다. 최대 누적값들을 무조건 합치지 않는다.
- CE = 방전용량 / 충전용량 × 100. EE = 방전에너지 / 충전에너지 × 100. 양의 분모가 없으면 빈 값으로 남긴다.
- 유지율은 선택 기준 Cycle의 방전용량과 방전에너지를 각각 100%로 환산한다. 에너지가 없는 기준 Cycle에서는 에너지 유지율을 계산하지 않는다.
- 기존 Qt의 CC/CV 전압 허용폭과 onset 저항 계산은 호환 목적으로 재사용한다. onset 저항과 지정 시각 DCR은 서로 다른 지표이며 이름을 혼용하지 않는다.
- `step_sum`에서 CC/CV 용량·시간은 물리 Step별 값을 더한다. onset 전압·저항은 대표 Step에서 계산한다.

## Raw와 미분

- Raw 선은 물리 Step, 파일, Cycle, 상태 방향, 원본 행 누락, 시간 초기화 및 큰 시간 공백에서 분리한다. 떨어진 구간을 임의로 연결하지 않는다.
- 미분 기본 선택은 같은 Cycle·방향의 연속 물리 구간 중 측정점이 가장 많은 구간이다. StepNo 또는 PhysicalStepID로 직접 지정할 수 있다.
- 물리 구간 안의 용량 초기화도 분리한다. 선택한 구간과 실제 원본 행을 결과에 연결한다.
- 보존 Qt 엔진을 사용해 전압축에서 Q를 보간하여 dQ/dV를 계산하고, 용량축에서 V를 독립 보간하여 dV/dQ를 계산한다. 단순 역수로 대체하지 않는다.
- 기본값: 500 보간점, SG 활성화, 21점 자동 윈도, 3차 다항식, 피크 민감도 5%. SG는 기존 순서대로 보간 곡선 및 미분 곡선에 각각 적용된다.
- 보간점은 50~20,000 정수, 수동 윈도는 5 이상·보간점 미만의 홀수, 다항식 차수는 1~5이며 윈도보다 작아야 한다.
- 충전 CV 제외, 중복 전압/용량 평균 처리, 방전 피크 부호와 끝단 피크 제외는 기존 Qt 규칙을 유지한다.
- 선택 기능인 피크 간격 mV는 실제 보간 전압 범위에 따라 샘플 간격으로 변환한다. 보간점을 늘리는 것이 원본 측정 해상도를 높이는 것은 아니다.
- 미분 곡선 Hover는 계산점이고 Raw Hover는 실측점이다. 결과에는 계산 버전, 설정 식별자, Step 선택, 실제 전압 범위를 남긴다.
- 피크 추이는 같은 시험·방향 안에서 허용 전압 이동폭 내 일대일 최근접 매칭을 사용한다. 사라진 피크는 `missing`, 새 피크는 `new`로 표시한다. 물리적 반응의 동일성을 자동 보증하는 기능은 아니다.

## 분할 시험 연결과 프로젝트

- 서로 다른 셀은 자동으로 연결하지 않는다. 사용자가 같은 셀임을 확인하고 파일별 Cycle Offset을 직접 지정할 때만 연결한다.
- 연결 후 Cycle이 겹치면 오류를 반환한다. 하나의 Cycle 도중 분할된 파일을 자동 결합하는 기능은 제공하지 않는다.
- 원본 Cycle, 원본 행, 원본 채널 ID, 연결 Offset은 별도 보존한다. 기존 채널을 덮어쓰지 않는다.
- 프로젝트는 UTF-8 JSON으로 원본 참조·식별 정보·설정·수동 변경을 저장하며 원본 대용량 데이터를 기본 복제하지 않는다. 원본 재연결과 해시 비교는 프로젝트를 여는 앱에서 수행한다.

## 현재 검증 범위

`tests/test_analysis.py`는 기존 Qt 엔진과의 단일 Step 기본값 수치 일치, 기준 Cycle 검증, 검토 상태 제외, 물리 Step 분리, Raw 행 공백, 잘못된 설정, 피크 일대일 대응, 명시적 분할 시험 연결을 검사한다. `tests/test_project.py`는 한글 경로·설정·수동 수정·원본 식별 정보의 JSON 왕복과 지원하지 않는 버전 거부를 검사한다.

이 테스트들은 합성 데이터 기반이다. 실제 PNE 장비 파일과 회사 PC의 EXE 검증을 대신하지 않는다.
